


# ログ
ユーザーが機能追加における気づきやログを備忘ログや引継ぎとして使うためのファイル。  
ユーザーのみが編集すること。


# 設計方針
ユーザーとともに設計の意図や方針についてまとめる。  
機能追加における関連ファイルやクラス、それらの責任領域についてまとめる。  



# 詳細設計
ユーザーともに実際のプログラムにおける引数やクラスの持つ関数などに関して定義する。  


# 実装レポート
設計方針と詳細設計を基に実際のプログラムを追加し、その際に発生した課題や問題点、その対応について記録する。  
また、これらの原因について分析・記録するとともにこの手順書の最適化に活用する。
