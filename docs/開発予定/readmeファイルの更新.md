# 更新項目

## Googleカレンダー連携のGCP設定手順
関連: `開発予定/202610_GCalの認証情報保持/202610_GCalの認証情報保持_要件定義.md`

> **反映時に再確認すること（2026-10-25時点の内容）**  
> 以下は要件定義の段階でまとめたもので、まだ実装していない。readmeに反映する前に、次の点を実装・実機の動きと照らし合わせて確認し直すこと。
> - 設定UIの表示・チェックボックスの名前（要件定義1.8節）
> - メッセージの文言・表示される場面（要件定義1.3節・1.5節）
> - 権限の説明文の文言（要件定義1.2節）
> - GCPコンソールの画面名・手順が変わっていないか（Google側の画面は変わることがある）

Booth配布物には `client_secret.json` を同梱しないため、ユーザー自身にGCPの設定をしてもらう必要がある。その手順と注意点を記載する。  
readmeでは「再起動」と書かず、「アプリを終了して起動し直す」と書く（右クリックメニューに再起動の項目がないため）。

- [ ] GCPプロジェクトの作成と、Google Calendar API / Google Tasks API の有効化
- [ ] OAuth同意画面の設定（スコープ: calendar.readonly / tasks.readonly）
- [ ] OAuthクライアントID（デスクトップアプリ）の作成と `client_secret.json` のダウンロード
- [ ] `client_secret.json` をアプリ直下（exeと同じフォルダ）に配置する
- [ ] 設定で `get_calendar_info` の権限をオンにし、アプリを終了して起動し直す（権限の変更は起動し直した後に反映される）
- [ ] 初回起動時にブラウザで承認すると `oauth_token.json` が保存され、以降は自動で連携されることの説明
- [ ] ブラウザでの承認は5分以内に行うこと。過ぎた場合や「キャンセル」した場合は、アプリを終了して起動し直せば承認し直せること
- [ ] 連携の結果は起動時のメッセージに表示されること。失敗した場合は、原因に応じたメッセージが別に表示されること
- [ ] 連携の解除の方法: 権限をオフにして、アプリを終了して起動し直す（起動時にパソコン内の認証情報が削除される）。承認し直したいだけなら、アプリを終了して `oauth_token.json` を削除してから起動し直す
- [ ] 設定の「毎回承認する（承認情報を保存しない）」をオンにすると、承認情報をパソコンに保存せず、起動のたびにブラウザでの承認が必要になること（保存済みの承認情報は次回の起動時に削除される）

### 注意点として記載すること
- [ ] 公開ステータスが「テスト」のままだとリフレッシュトークンが**7日で失効**し、毎週ブラウザ認証が必要になる。「本番環境」に切り替えること
- [ ] 審査を受けていない本番アプリでは同意画面に「Googleはこのアプリを確認していません」という警告が出る。自分で作ったアプリなので「詳細」→「（安全ではないページ）に移動」で進めてよいこと
- [ ] 同意画面ではカレンダーとタスクの両方にチェックを入れること（片方だけだと連携に失敗する）
- [ ] `client_secret.json` と `oauth_token.json` は他人に渡さない・公開しないこと。特に `oauth_token.json` は暗号化されておらず、カレンダーへのアクセス権そのもの。アプリのフォルダをzipで共有したり、クラウドに同期したりするときは注意すること
- [ ] 「一度承認すれば以降は自動」の例外（次の場合は承認し直しになる）
  - 6か月間使われなかった（アプリを起動しなかった）
  - Googleアカウントの「サードパーティ製アプリとサービス」から、このアプリへのアクセスを削除した
  - GCPでOAuthクライアントを削除した
  - なお、`client_secret.json` を別のクライアントのものに差し替えたときは、`oauth_token.json` も削除してから起動すること（トークンに古いクライアント情報が入っているため、古いクライアントが残っていると差し替えが反映されない）
  - 承認し直しの動き: 起動時に分かった場合はそのままブラウザが開く。起動中に分かった場合はメッセージで知らせるので、アプリを終了して起動し直すと承認し直せる
- [ ] 権限をオフにしてもGoogle側の連携（同意）は自動では取り消さないこと
  - Google側の連携も消したい場合は、Googleアカウントの「サードパーティ製アプリとサービス」から自分で削除する
  - 同じ `client_secret.json` を複数のPCで使っている場合、Google側で削除するとすべてのPCの連携が切れる
- [ ] ネットワークにつながっていないときは連携が一時的に止まるが、つながれば自動で戻ること（認証情報は消えない）
